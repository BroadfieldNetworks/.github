# Broadfield Networks

Broadfield Networks develops, publishes, and operates software products.

## Products

### [Maxisnap](https://github.com/BroadfieldNetworks/maxisnap)

A Windows and macOS screenshot and screen-recording app for capture, annotation, OCR, local saving, and
optional sharing.

- [Product website](https://maxisnap.com/)
- [Official downloads](https://github.com/BroadfieldNetworks/maxisnap/releases)
- [Documentation](https://maxisnap.com/help/)
- [Support](https://maxisnap.com/contact/)

### [ProofScene](https://github.com/BroadfieldNetworks/proofscene)

3D print proofing and artwork approval software that turns proof-sheet PDFs into interactive 3D
proofs for cards, packaging, lanyards, wristbands, and other printed products.

- [Product website](https://proofscene.com/)
- [Live 3D demo](https://proofscene.com/demo/)
- [Free print and card tools](https://proofscene.com/tools/)
- [Guides](https://proofscene.com/guides/)
- [Support](https://proofscene.com/contact/)
